# config/ — всё, что отличает один магазин от другого

Код одинаков для всех проектов, сделанных из шаблона. Клиентское живёт здесь и в `.env`.

## shop.json

| Поле                   | Тип                             | Назначение                                                                 |
| ---------------------- | ------------------------------- | -------------------------------------------------------------------------- |
| `name`                 | строка, 1–80                    | Название магазина (шапка, манифест TonConnect, уведомления)                |
| `description`          | строка, до 500                  | Подзаголовок на главной                                                    |
| `defaultLocale`        | `ru` \| `en` \| …               | Язык по умолчанию; должен входить в `locales`                              |
| `locales`              | массив кодов                    | Для каждого кода нужен файл `i18n/<code>.json`                             |
| `currencies`           | подмножество `TON`, `USDT`      | Какие валюты показываются в чекауте                                        |
| `usdt.label`           | строка, 1–16                    | Как называть jetton в интерфейсе (обязателен при USDT)                     |
| `usdt.decimals`        | целое 0–18                      | Десятичные знаки jetton-а (у Tether USDT — 6)                              |
| `support.url`          | URL, необязательно              | Ссылка на поддержку                                                        |
| `links.terms`          | URL, необязательно              | Условия использования (манифест TonConnect)                                |
| `links.privacy`        | URL, необязательно              | Политика конфиденциальности                                                |
| `branding.accentColor` | `#RRGGBB`                       | Основной цвет интерфейса (кнопки, ссылки, фокус)                           |
| `branding.icon`        | `.png` или `.ico` в `branding/` | Иконка 180×180 для манифеста TonConnect (PNG предпочтительнее, SVG нельзя) |

Адрес мастера jetton-а (`USDT_JETTON_MASTER`) и кошелёк мерчанта задаются в `.env`, не здесь.

## products.json

Стартовый каталог. Массив объектов:

| Поле              | Тип                           | Назначение                                                     |
| ----------------- | ----------------------------- | -------------------------------------------------------------- |
| `slug`            | `[a-z0-9-]`, уникален         | Ключ товара для seed                                           |
| `title`           | строка, 1–120                 | Название                                                       |
| `description`     | строка, до 2000               | Описание                                                       |
| `imageUrl`        | URL, необязательно            | Картинка                                                       |
| `priceTon`        | десятичная строка             | Цена в TON, например `"1.5"` (до 9 знаков после точки)         |
| `priceUsdt`       | десятичная строка             | Цена в USDT, до `usdt.decimals` знаков                         |
| `deliveryPayload` | строка, до 4000               | Что выдаётся после оплаты: ссылка, код, текст                  |
| `deliverInChat`   | boolean, по умолчанию `false` | Дублировать payload в сообщении бота (иначе только в Mini App) |
| `isActive`        | boolean, по умолчанию `true`  | Показывать в каталоге                                          |
| `sortOrder`       | целое, по умолчанию `0`       | Порядок в каталоге                                             |

Хотя бы одна из цен обязательна. Суммы пишутся строками, не числами: они превращаются в
bigint без потери точности.

**Правило seed.** `pnpm db:seed` только добавляет товары, которых ещё нет по `slug`.
После первого запуска источник истины — база и админка: правки цен и текстов в админке
seed не перезаписывает. `pnpm db:seed --overwrite` осознанно пересинхронизирует
title, description, imageUrl, цены, deliveryPayload и deliverInChat по slug, не трогая
`isActive` и `sortOrder`.

**Внимание.** `deliveryPayload` в этом файле виден всем, у кого есть доступ к репозиторию.
Для реальных ссылок и кодов заполняйте товары через админку.

## i18n/<locale>.json

Плоский словарь `ключ → строка`. Наборы ключей во всех языках должны совпадать.
Плейсхолдеры вида `{{orderId}}` подставляются при отправке уведомлений.

Языки `ru` и `en` уже подключены. Новый язык требует одного изменения кода вне `config/`:
строки импорта словаря в `apps/web/src/lib/i18n.ts`. Если файл не подключён, сборка
витрины падает с понятной ошибкой.
